# Reporting Security Issues

If you discover a security issue in httpyac, please report it privately through
the [ZeroWiggliness/httpyac security advisories](https://github.com/ZeroWiggliness/httpyac/security/advisories/new).

This will allow us to assess the risk, and make a fix available before we add a
bug report to the GitHub repository.

Thanks for helping make httpyac safe for everyone.
